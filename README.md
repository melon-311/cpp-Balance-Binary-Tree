# 平衡二叉树

基于C++开发的课程设计平衡二叉树，在AI的辅助调试下，实现了平衡二叉树的各项基础算法，如各种遍历、查找、删除等。

---

## 快速开始

### 编译环境
- 支持 C++11 或更高版本（如 g++、clang++）

### 编译与运行
```bash
g++ main.cpp -o avl
./avl
```

### 使用说明
运行后按提示手动输入数字（如 `5 3 7 1 4`），程序会构建平衡树并输出遍历结果。

---

## 功能列表
- 插入节点
- 删除节点
- 前序/中序/后序遍历
- 查找指定元素等
